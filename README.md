# PODBAY / закрытый просмотр 360°

Это версия конструктора для просмотра в браузере. Этикетки, исходные SVG, модель банки и рабочие файлы хранятся в зашифрованном виде. Пароль передаётся отдельно и в репозитории отсутствует.

Откройте сайт GitHub Pages, введите пароль и вращайте банку мышью или пальцем. В разделе «Файли та перевірка для дизайнера» есть редактируемые SVG и ссылка на Figma. Доступ к Figma-файлу выдаётся его владельцем отдельно.

Макеты являются дизайн-версиями, не финальным файлом для печати.
